# Walmart Sales Prediction - Multiple Regression Model

## Overview

This project is part of my **Capstone Project** for my Master's program in Data Science. The main goal of this research is to build a **multiple regression model** to predict the weekly sales of Walmart stores across various locations. The model takes into account several factors such as:

- **CPI (Consumer Price Index)**
- **Unemployment rate**
- **Holidays**
- **Fuel prices**
- **Temperature**
- **Number of stores**
- **Dates**

These factors are analyzed to understand their influence on the weekly sales performance across different Walmart locations. This model aims to help Walmart optimize its supply chain, forecast sales, and improve overall business strategies.

## Project Details

In this repository, you will find:

- The dataset used for building the model
- Code and scripts for data preprocessing, feature engineering, and model building
- Results and evaluation of the model's performance

The model uses **Multiple Linear Regression** and includes the necessary steps for data cleaning, exploratory data analysis (EDA), and feature selection.
